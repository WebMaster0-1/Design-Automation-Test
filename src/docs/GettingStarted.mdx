# Getting Started

This page covers everything you need to integrate the FMDQ Design System into your project from local setup to using your first component.

### Prerequisites

Ensure the following are available in your environment before proceeding:

◼ **Node.js** v18 or higher <br></br>
◼ **npm** or **yarn**

---

### Installing in Your Project

Add the design system package to your project:

```bash
npm install @fmdq/design-system
```

Import the global stylesheet once at your application's entry point (e.g. `main.ts` or `index.js`):

```js
import '@fmdq/design-system/styles/global.css';
```
This loads all design tokens; colours, spacing, typography, shadows as CSS variables.

---

### Using a Component

Import and use components directly:

```jsx
import { Button } from '@fmdq/design-system';

<Button variant="primary" label="Submit" />
```

Each component page includes a **Controls** panel where you can adjust props and preview variants live. 
Use the **"Show code"** option at the bottom of any preview to copy the exact JSX for your selected configuration.
