# App Top Bar

App top bar: product top bar beside the Sidebar (1168 wide at 1440). Left: admin menu as Line tabs (Home, Activity, Users, My Requests; set active, rename the 4th to Authorisations for authorisers, never both). Right: notifications bell with unread count (opens Notification / panel) and the account menu (opens Sidebar / account menu). Fixed on scroll. Props: Name, Role, has notifications, has admin menu.
