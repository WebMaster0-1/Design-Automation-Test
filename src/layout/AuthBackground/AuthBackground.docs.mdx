# Auth Background

## Overview

Login and set-up background: Primary/900 with the animated dotted shader from the profile-card exploration. Placed behind the Auth card on every Flow 1 auth screen.

The Figma iframe placeholder has been replaced by a native Three.js GLSL background. No login form or other UI is included. Dot geometry and metallic grain remain fixed while irregular gold folds stretch, bunch, and change direction across the surface.

The surface colors are scoped CSS tokens; gold now follows the shared `--color-fmdq-gold` (#CC9933) token per updated art direction. Primary/900 uses the existing shared token. The focus vignette uses Figma's 1100×1000 reference bounds and 92% / 75% / 0% opacity stops. The procedural contours reconstruct the proprietary Figma SHADER fill: its GLSL source is not exposed. Motion runs at 70% of the previous pace. Gold coverage ebbs through sparse, blue-dominant moments (approximately 90% blue / 10% gold as an art-direction target) and fuller folds. Narrow crease cores coexist with asymmetrically feathered shoulders; edge definition varies locally. Broad spatial scales and restrained domain warping keep bends open and gently rounded rather than tightly curled. Occasional larger draped arcs add a bright hem and a softly shaded face, blending by maximum to avoid accumulating excess gold. Continuous 3D noise and domain warping create non-directional, Brownian-like fold evolution; no repeating stripe phase or frame-randomized jitter is used. This is not a claim of frame-for-frame shader parity.

## Usage guidelines

Use the default story for a background-only full-window preview. Use the object control to edit the named shader properties and `paused` to freeze motion. The native renderer respects reduced-motion preferences, skips drawing in hidden tabs, caps drawing at 30 fps and device pixel ratio at 1.5, and disposes GPU resources on unmount. WebGL-unavailable environments receive a static dotted fallback.

The optional children slot remains available for later integration; all provided stories leave it empty. Color token overrides should be set before mounting the renderer. No Figma login or network request is needed to display the native background.
