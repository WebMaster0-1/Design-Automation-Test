## Implementing Design Tokens

All foundations are exported as CSS custom properties (variables) defined in `tokens.css`. You can reference these variables directly in your CSS files:

```css
.card {
  background-color: var(--color-neutral-white);
  padding: var(--spacing-4);
  border-radius: var(--radius-8);
  box-shadow: var(--shadow-sm);
}
```
