# Typography

Typography is the foundation of the FMDQ digital experience. It dictates legibility, hierarchy, and brand personality across all platforms. We utilize **DM Sans** as our primary typeface for clean, modern readability, and **Rubik** as a secondary brand typeface.

  ## Component API

  Use these components to implement the typography scale in your applications. Each component is pre-configured to match our design system tokens.

  ### Heading
  Used for titles and section headers. Supports levels `display-lg`, `display-sm`, and `1-6`.
  
  <Canvas>
    <div style={{ display: 'flex', flexDirection: 'column', gap: '20px' }}>
      <Heading level="display-lg">Display Large</Heading>
      <Heading level="1">Heading 1</Heading>
      <Heading level="2">Heading 2</Heading>
      <Heading level="3">Heading 3</Heading>
    </div>
  </Canvas>

  ### Text
  The workhorse component for all body text, paragraphs, and captions.
  
  <Canvas>
    <div style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
      <Text size="lg">Large body text for emphasized paragraphs.</Text>
      <Text size="md">Medium body text (Default) for standard content.</Text>
      <Text size="sm">Small body text for secondary information.</Text>
      <Text size="caption-lg" weight="semibold">CAPTION LARGE FOR UPPERCASE LABELS</Text>
    </div>
  </Canvas>

  Used for forms, metadata, and small UI annotations.
