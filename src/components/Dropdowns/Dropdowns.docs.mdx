# Dropdowns

Two families from the Figma **"✤ Dropdowns"** page. **Menu** is a trigger that opens a command-style popover. **Selectors** is a form field that opens a list of options — per Figma, it *"combines the functionality of input fields and dropdowns"*, so it composes the existing `Input` element rather than re-implementing a field.

## Notes

- **Reuse.** The field is `Input size="lg"` (already h56 / r12 / 1px neutral-300 / gap 12). Avatars are `Avatar`, checkmarks are `Toggle type="Checkcircle"`, icons come from `foundations/icons`.
- **Scoped overrides.** Three, none of which touch the shared components: Toggle 24→16px, Toggle colour fmdq-blue→secondary-400, and the leading-icon gap 12→8px.
- **Tokens.** Every Figma hex mapped to an existing token. Two were added: `--radius-6` and `--shadow-dropdown-menu`. The selector popover's shadow was an exact `--shadow-normal-xsm` match.
- **Interaction states.** `hover` / `focused` / `active` work both as props (so every Figma variant has a story) and as real CSS pseudo-classes. `selected`, `disabled` and `filled` are props only.

## Usage

Use **`DropdownsMenu`** for actions and navigation; use **`DropdownsSelector`** for form input that holds a value. Label every selector clearly and keep placeholder text as guidance, never as a substitute for the label. Avoid menus whose options change based on another menu's selection.
