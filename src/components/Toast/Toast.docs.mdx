# Toast & Alerts

The `Toast` (also exported as `Alert`) component matches the **FMDQ Design System** `Alert / Toast / Notification` component set in Figma.

It provides both:
1. **Compact Toasts (`type="toasts"`)**: Lightweight notifications (width 390px) designed for floating updates.
2. **Alert Banners (`type="banners"`)**: Rich in-flow messages (width 568px) with structured titles, descriptions, and action CTA buttons.

## 2. All 4 Semantic States (Toasts)

Supported states:
- `information`: Dark blue streak (`#1D326D`), light blue badge, info icon.
- `success`: Green streak (`#04802E`), light green badge, check-circle icon.
- `warning`: Gold streak (`#DD900D`), light gold badge, warning triangle icon.
- `error`: Red streak (`#CB1A14`), light red badge, error check/alert icon.

## 4. Imperative Usage (`useToast`)

You can trigger floating toasts anywhere in your application using `ToastProvider` and the `useToast` hook:

```tsx
import { ToastProvider, useToast, Button } from '@fmdq/design-system';

function MyComponent() {
  const { toast } = useToast();

  return (
    <Button
      label="Submit"
      onClick={() =>
        toast({
          state: 'success',
          title: 'Changes Saved',
          description: 'Your settings have been updated.',
          duration: 4000,
        })
      }
    />
  );
}
```
