## Architecture

1. **Brand Logo (`Logo` / `FmdqLogo`)**:
   - Reusable element exported from `src/elements/Logo`.
   - Default transparent mode for light surfaces, Card mode (`Property 1=DarkBG`) with clean white container for dark themes.
2. **Cells (`SidebarMenuItem`, `SidebarSubMenuItem`)**:
   - Types: `default`, `multi-layered` (with expandable nested tree), `icon-only` (collapsed mode).
   - States: `default`, `hover`, `selected`.
   - Themes: `light`, `blue`, `dark-blue` (gold icon strokes `#CC9933`), `dark-grey`.
   - Counters: Connected to design system `<Badge size="sm" type="accent" color="neutral" />` (#F0F2F5 background, #344054 text).
   - Typography: 14px DM Sans (`--font-size-p-sm`), 400 default/hover, 600 selected.
3. **Rows (`SidebarSection`)**:
   - Section Title: 14px DM Sans Medium (`--font-size-p-sm`, 500) and optional bottom divider.
4. **Column (`Sidebar`)**:
   - **Variant 1**: Brand logo top, search bar, menu sections, user profile card & account flyout at bottom.
   - **Variant 2**: User profile card top with chevron selector, search bar, menu sections, brand logo at bottom.
   - **Collapsed Mode**: 82px width with `align-justify` (☰) hamburger button and centered icon-only items.
