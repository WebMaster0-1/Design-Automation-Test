# Notification Panel

Notification / panel: opens from the top bar bell. Header with Mark all as read (Button / texts), All and Unread Line Tabs with counts, a list of Notification / item rows (newest first, unread on Grey/50 with a dot), and a View all alerts footer. state=empty uses the DS Empty State (Notifications). Width 400, radius 12, Shadow/Normal/large. Dev: list caps at about 5 rows then scrolls with the DS Scrollbar; clicking a row marks it read and opens its source.

## Variants / States

### Default State
Displays notification list with unread markers, tabs with unread counters, and mark all as read action.
