# Dropdown / Selectors

The `Dropdown` (and `DropdownSelector`) component is aligned 1:1 with the **FMDQ Design System** `Dropdown / Selectors` component set in Figma.

It provides a rich form selector field supporting 4 variant types, 5 interactive states, custom options with sublabels, leading graphics, and backward compatibility for custom action trigger menus.

---

## 1. Default Selector

The standard text-only selector with a label and chevron indicator.

## 2. Variant Types

Dropdown selectors support four leading graphic types matching Figma:

1. **Default**: Standard text without leading graphics.
2. **Icon Leading**: Heart or custom leading SVG icon.
3. **Avatar Leading**: User profile image or initials avatar.
4. **Status**: Real-time system or connectivity status indicator dot.

## 3. Visual States Matrix

The selector supports five states:
- **Default**: Neutral border (`#D0D5DD`), placeholder text in grey.
- **Hover**: Amber hover border (`#F7D394`).
- **Active / Focused**: Gold active border (`#F3A218`) and subtle focus glow.
- **Filled**: High-contrast dark text (`#101928`) displaying the selected option.
- **Disabled**: Neutral grey background (`#F0F2F5`) and disabled cursor.

## 4. Extended (Open Menu) State

When open, the component displays the `.Selector menu / menu list` containing options with primary titles and secondary handles (e.g. `@account`).
