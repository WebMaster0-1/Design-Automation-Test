# Dropdown / Menu

The `Dropdown` component is aligned 1:1 with the **FMDQ Design System** `Dropdown / Menu` (`2190:52619`) and `Dropdown / menu item` (`2159:51455`) component set in Figma.

It serves as the contextual action and navigation menu popover, supporting 3 trigger variants (`default` button with chevron, `avatar`, `icon-only` button), multi-section popover menus with headers, keyboard shortcuts, toggle indicators, and destructive actions.

> **Note on Form Selectors**: Form dropdown inputs with labels, helper text, and selection fields belong to `Input / Input Dropdown` (`Dropdown / Selectors` in Figma `2198:54679`).
