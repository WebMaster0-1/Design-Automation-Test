## Usage Guidance

Wide data tables that scroll sideways, because desktop browsers can hide native scrollbars. Long lists or panels inside a fixed area. Use it only when content really overflows. Show the whole table when it fits.

## Modern CSS Scrollbar Utility (`.fmdqui-scrollable`)

In addition to the `<Scrollbar>` React element, the design system exposes CSS utility classes to style native browser scrollbars using standard CSS properties (`scrollbar-color`, `scrollbar-width`):

```css
/* Apply to any overflow container */
.my-scrolling-container {
  overflow: auto;
  scrollbar-color: var(--color-neutral-300) var(--color-neutral-100);
  scrollbar-width: thin;
}
```

Or apply the utility class:
```html
<div class="fmdqui-scrollable">...</div>
<div class="fmdqui-scrollable fmdqui-scrollable--dark">...</div>
```
